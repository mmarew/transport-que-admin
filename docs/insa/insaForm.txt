- Asset Detail:
  Dynamics Queue Admin is the dispatch-queue management console of the Dynamics
  freight marketplace. It is a React single-page application served from
  queue.dynamicsroute.tech that authenticates queue staff by phone + OTP (httpOnly
  cookie session) and lets a loading place (Queue Organization) register and pass
  platform approval, run a GPS-proven FIFO driver check-in queue with an immutable
  audit trail, dispatch drivers, override and remove queue entries, view entry
  history, bid on a shipper's freight on the shipper's behalf, manage members and
  vehicle types, view queue reporting, and track its own INSA Secure Website
  Management Standard compliance. It consumes the Dynamics backend REST + Socket.IO
  API and does not store session tokens in the browser.
